# 프릿지 OSMU 콘텐츠 엔진 — Google Apps Script 버전

Netlify·GitHub·PC 로컬 서버 없이, **구글 시트만으로 배포**하는 버전입니다.
오늘 겪었던 GitHub 권한 문제, Netlify 크레딧 문제, Windows 로컬 서버 문제를 전부 우회합니다.

## 배포 방법 (10분 이내)

### 1. 구글 시트 새로 만들기
[sheets.google.com](https://sheets.google.com) → 새 스프레드시트 생성 → 이름을 "프릿지 OSMU 엔진"으로 변경

### 2. Apps Script 편집기 열기
메뉴 **확장 프로그램 → Apps Script** 클릭

### 3. 코드 붙여넣기
- 기본 생성된 `Code.gs` 파일 내용을 전부 지우고, 이 폴더의 **`Code.gs`** 내용을 붙여넣기
- 왼쪽 파일 목록에서 **+ → HTML** 클릭 → 파일명을 정확히 **`Index`** 로 저장 → 이 폴더의 **`Index.html`** 내용을 붙여넣기

### 4. 시트 탭 준비
Apps Script 편집기 상단 함수 선택 드롭다운에서 **`setupSheets`** 선택 → **실행(▶)** 버튼 클릭
(처음 실행 시 권한 승인 화면이 뜨면 본인 계정으로 승인)

→ 원본 스프레드시트로 돌아가면 **Brand_Rules**, **Content_History** 탭이 자동 생성되어 있습니다.

### 5. API 키 등록
Apps Script 편집기 왼쪽 **프로젝트 설정(⚙️)** → **스크립트 속성(Script properties)** → **속성 추가**

| 속성 이름 | 값 | 필수 여부 |
|---|---|---|
| `GEMINI_API_KEY` | 발급받은 제미나이 키 | **필수** (없으면 생성 자체가 안 됨) |
| `CLOUDINARY_CLOUD_NAME` | Cloudinary 값 | 발행 기능 쓸 때만 |
| `CLOUDINARY_API_KEY` | Cloudinary 값 | 〃 |
| `CLOUDINARY_API_SECRET` | Cloudinary 값 | 〃 |
| `IG_USER_ID` | 인스타그램 값 | 인스타 자동발행 쓸 때만 |
| `IG_ACCESS_TOKEN` | 인스타그램 값 | 〃 |
| `THREADS_USER_ID` | 스레드 값 | 스레드 자동발행 쓸 때만 |
| `THREADS_ACCESS_TOKEN` | 스레드 값 | 〃 |

(지금은 `GEMINI_API_KEY`만 있어도 "문구 생성"까지는 바로 테스트 가능합니다.)

### 6. 웹앱으로 배포
Apps Script 편집기 오른쪽 위 **배포 → 새 배포**
- 유형: **웹 앱**
- 설명: 아무거나 (예: v1)
- 다음 사용자 인증 정보로 실행: **나**
- 액세스 권한이 있는 사용자: **아무나** (링크로 접속 가능하게)
- **배포** 클릭 → 권한 승인 → 생성된 **웹 앱 URL** 복사

### 7. 접속해서 테스트
복사한 URL을 새 탭에 붙여넣으면 바로 화면이 뜹니다. 콘텐츠 유형·브랜드·핵심 메시지 입력 후 "문구 생성" 클릭.

## 코드 수정 후 재배포

`Code.gs`나 `Index.html`을 다시 수정하면, **배포 → 배포 관리 → 수정(연필 아이콘) → 새 버전 → 배포**를 다시 눌러야 웹 앱에 반영됩니다 (URL은 그대로 유지됨).

## 이 버전의 특징

- **인증 없이 바로 배포**: GitHub/Netlify 계정, PC 서버 불필요 — 구글 계정만 있으면 됨
- **Brand_Rules 탭**: 페르소나·키워드·금지어를 시트에서 직접 수정 가능 (코드 수정 없이)
- **Content_History 탭**: 생성/발행 이력이 자동으로 시트에 쌓임 — 나중에 엑셀처럼 열어서 확인 가능
- **채널별 발행**: 인스타그램·스레드는 이미지 업로드 후 즉시 자동 발행, 네이버블로그·프릿지매거진은 복사 버튼 제공
