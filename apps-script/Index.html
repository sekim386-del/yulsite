1) 스크립트 속성에 THREADS_APP_ID, THREADS_APP_SECRET을 먼저 등록하세요 (Meta 앱 대시보드 → 이용 사례 → Threads API 액세스 → 설정 탭에서 확인).
2) 아래 "리디렉션 URI 확인" 버튼으로 나온 주소를 그 설정 탭의 리디렉션 URI 등록란에 추가하세요.
3) "스레드 연동 시작" 버튼을 눌러 로그인 승인하면 토큰이 자동 저장됩니다.
